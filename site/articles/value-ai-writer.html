Value AI Writer byGMOの料金と使い方｜無料枠と有料の線引き2026

最終更新：2026年11月27日 ｜ カテゴリ：文章作成 ｜ 情報確認日：2026年11月27日
結論：Value AI WriterはSEO記事を量産したい人向けのライティングツールです。まずフリープランで記事生成を1本試し、継続的に記事を出す必要が出てきたら有料プランへ。月いくらで元が取れるかを先に計算するのが失敗しない順番です。

Value AI Writerとは

GMOデジロック株式会社（バリュードメイン）が提供する、SEOに特化した記事作成AIツールです。キーワードをもとにタイトル案、見出し構成、本文を生成し、WordPress連携まで画面上で完結できます。本文生成には GPT-4o / GPT-4.1 / Claude 4.0 / Gemini 2.5 Pro から対応モデルを選べます（公式サイト、2026年11月確認）。

一般的なチャット型AIに毎回細かく指示を出す方法と違い、「キーワード調査 → 構成案 → 本文生成 → リライト → WordPress投稿」という記事制作の一連の流れをひとつのツール内で進められる点が特徴です。公式では「作業時間が1/10、外注費換算でコスト1/100」という自社調べの数値も掲載されています（自社調べのため、実際の効果は用途により異なります）。

公式料金表では、フリーからエキスパートまで 7段階 のプランが案内されています。下表の記事数は「初回増量を含まない通常枠」です（公式ではフリー初回3記事、エントリー初回6記事という増量も掲載）。

無料枠でできること・できないこと

  • できる：月1本の記事生成（初回のみ3本）、タイトル・見出し・本文の生成、HTML出力、WordPress連携
  • 制限がある：生成できる本数、本文生成文字数、リサーチ系の一部機能（サジェストキーワード調査はプロ以上、被リンクドメイン調査はエキスパート限定）
  • 注意点：AI生成文はそのまま公開せず、事実確認と編集が前提です

「無料で1本作り切れるか」を確認してから有料化を判断するのが、無駄な出費を避ける順番です。生成時間だけでなく、事実確認や修正にかかる時間も測ってみると、自分の運用に合うか判断しやすくなります。

上位プランで使えるリサーチ機能

Value AI Writerの差別化は、単なる文章生成ではなくSEOのリサーチ機能が揃っている点にあります。公式サイトで案内されている主な機能は次の通りです。

  • キーワード難易度調査：自サイトのSEO評価と検索結果の競合状況から、難易度を5段階で判定。今のサイトで狙うべきキーワードかが分かります（全プラン共通）。
  • サジェストキーワード調査（プロ・エキスパート限定）：最大100個のサジェストキーワードを月間検索数付きで一括抽出。
  • 被リンクドメイン調査（エキスパート限定）：競合サイトのURLから被リンク元を最大100件抽出。リンク構築の戦略に使えます。
  • キーワード発掘：競合だけが上位を取れているキーワードを抽出し、取りこぼしていたトピックを発見します。

副業でブログを運営するなら、まずはフリー／エントリーで記事生成の流れを確認し、リサーチ機能が必要になった段階で上位プランに上げるのが費用対効果の良い順番です。

更新と解約のルール（重要）

公式の変更・解約ガイドでは、解約は予約方式で、自動更新が行われる有効期限日の 5日前まで に手続きが必要と案内されています。その他にも次の点を確認しておきましょう。

  • 契約は1ヶ月単位のサブスクリプションで、有効期限の5日前から毎日0時に自動更新されます
  • アップグレードは月額差額の請求で、日割り計算はありません
  • ダウングレード時の差額返金はありません
  • 更新失敗・解約予約後の契約は、期限切れ後最大30日間復旧可能です
  • 公式マニュアルに「5日間無料」という表記も残っていますが、フリープランとは別のキャンペーンです。実際に選択したプランの申込画面を確認してください

有料化の判断基準

  1. フリープランで1本記事を最後まで作り切れるか確認する
  2. 月に何本出す必要があるかを決める（例：月5本なら エントリー840円〜）
  3. 記事1本あたりのコストが、得られる収益や時給に見合うか計算する
  4. 自動更新・解約方法（有効期限5日前まで）を事前に読んでおく

こんな人に向いています

  • 日本語のブログやオウンドメディアを定期的に更新している副業層
  • キーワード調査から構成・本文・WordPress投稿までを一つのツールで完結させたい人
  • 外注費を抑えつつ、記事の品質は自分でチェックしたい人
  • 円建てで請求される国内サービスを使いたい人

向いていない人・注意が必要な人

  • AIの出力を自分で検証・編集する時間を取れない人（公式も目視確認を案内しています）
  • 英語記事が主力で、日本語SEOの機能をあまり使わない人（Writesonicなどの方が合う場合があります）
  • 体験談や一次情報のない記事を量産したい人（生成できるのは文章のみ。独自情報は自分で追加する必要があります）

生成した文章をそのまま公開するのではなく、事実確認・独自情報の追加・文字装飾を行ってから公開するのが前提です。公式も「投稿するコンテンツの責任は投稿者に帰属する」と案内しています。

主要機能を画像で解説

公式サイトの画面を確認しながら、各機能を具体的に見ていきます（2026年11月確認）。

① キーワード調査

キーワード難易度を自サイトの評価と検索結果から5段階で判定できます。今のサイトで狙うべき語かを判断する材料になります。サジェストキーワード調査はプロ以上、被リンクドメイン調査はエキスパート限定です。フリープランでは全機能は使えません。

② 構成生成

キーワードをもとにタイトル案と見出し構成を組み立てます。白紙から構造を考える手間を省き、記事の骨格を先に決められるのがメリットです。生成された見出しは検索意図に合わせて自分で整えてください。記事数はプランごとに上限があります。

③ 本文生成

構成に沿って本文を書き上げます。GPT-4o、GPT-4.1、Claude 4.0、Gemini 2.5 Proから対応モデルを選べます（公式サイト、2026年11月確認）。AI生成文はそのまま公開せず、事実確認と編集を行う前提で使ってください。

④ リライト

既存の文章の言い換えやトーンの調整に使えます。古くなった記事を刷新する場面や、読み手に合わせて表現を変えたい場合に便利です。リライト後も事実関係と独自情報の有無を確認してください。生成できる本数はプランの枠に縛られます。

⑤ WordPress連携

生成した記事をWordPressへ反映する操作まで画面内で完結できます。HTML出力にも対応しているため、別のCMSに貼り付ける方法も選べます。接続設定や投稿時の権限は利用環境によって異なるため、事前に確認してください。

⑥ 文字数制限

記事数とは別に、本文生成で使える文字数の上限が設定されています。選ぶモデルによって枠が異なるため、申込時には「記事数」と「文字数」の両方を確認する必要があります。長い記事を書く予定なら、文字数枠が大きいプランを選ぶのが安心です。

※ 機能・制限は変更される場合があります。最新情報は公式サイトでご確認ください。
