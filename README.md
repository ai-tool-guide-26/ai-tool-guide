## 調査の結論（要約）

1. **ChatGPT / Claude / Gemini / Midjourney には個人向けの現金紹介料プログラムは無い。** 周辺ツールを紹介する形で収益化する。
2. **日本は利用率約6割・目的は「調べ物」が約7割。** 比較記事と相性が良く、有料化意向（61.41%）が高い層が狙い目。
3. **海外は1件あたりの報酬が大きい**（Semrush $100〜$300、Surfer 初月75〜125%、GetResponse 40〜60%×12か月）。ただし英語記事・高競争・成果までのリードタイムが長い。
4. **日本在住でも海外ASPは運用可能。** PartnerStack は日本からの direct deposit（Airwallex）対応、impact.com は70通貨以上・$10最低出金。非居住者は **W-8BEN** を提出すれば源泉徴収を軽減できる（未提出だと30%）。
5. **報酬率・国別制限の変更が激しい。** 掲載前に公式で再確認し、確認日を記録する運用が必須。
