検索順位が上がる前に、まずはインデックスと「参考にされる」状態を作る。

## 2. アウトリーチ先（すべて無料・手動）

### A. まとめサイト／キュレーション
- **はてなブックマーク**：新着記事をブックマーク（自身のアカウントでOK）。公開日をずらして複数日で実施
- **Note**：上記の記事を投稿
- **Qiita**：「AIツール比較の情報設計（確認日・出典の扱い）」という切り口の技術記事にして投稿
- **Zenn**：同上。比较記事の「検証型」運用をノウハウとして書く

### B. コミュニティ（質問に答える形でURLを出す）

- Quora: 「What is the best AI writing tool for Japanese blogs?」に回答
- Slack/Discord のAI系コミュニティ（規約確認のうえ）

### C. 他ブログへの提案（相互リンクではない「引用」を狙う）

- 依頼文テンプレート（下記）

## 3. アウトリーチ文テンプレート

```
件名：AIツール料金の「確認日つき」比較表を公開しました

いつも拝見しています。
AIツールの料金・無料枠を、公式情報を確認したうえで
「確認日」つきで整理した比較ページを公開しました。

https://ai-tool-guide-26.github.io/ai-tool-guide/

もし記事内で「AIツールの料金が変わりやすい」という話を
書かれる際の参考リンクとして使っていただけると嬉しいです。
広告判定につながる記載はなく、アフィリエイト開示も明記しています。

ご迷惑でしたら削除してください。
```

## 4. 注意点
- 同じURLを短期間に大量投稿しない（スパム判定リスク）
- 相互リンクは「等価値のサイト」に限定する
- 有料の被リンク購入はしない（Googleガイドライン違反）
- 各投稿後にGSCの「リンク」レポートで取得状況を確認
